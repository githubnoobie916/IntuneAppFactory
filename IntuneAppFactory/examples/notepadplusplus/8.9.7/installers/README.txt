Place the approved Notepad++ installer here:
  npp.8.9.7.Installer.x64.exe

This filename must match install[].path in the adjacent app.json.
The installer is not included. Verify the vendor version and silent switches
before using this example. Do not rename this README to an installer filename.

For a different application, replace the installer and update app.json.
Only explicitly configured payload files are copied into the generated package.
